# 计划模板

## 必需工件路径

- `docs/requests/<request-id>/plan/plan.md`
- `docs/requests/<request-id>/plan/task-board.md`

## `plan/plan.md`

必需章节：

- 任务拆解
- 依赖关系
- 整洁性与复杂度控制
- 模式决策与替代方案
- 代码上下文与影响范围
- 并行执行建议（含是否值得启用 workflow）
- 触发与上下文准备
- 受影响文件或模块
- 测试策略
- 观察与人工介入点
- 回滚说明

## `plan/task-board.md`

每个任务必需字段：

- 任务 ID
- 任务名称
- 状态
- 执行模式（串行 / 可并行）
- 执行人或执行说明
- 触发/前置条件
- 关联规格区域
- 整洁性约束或注意点
- 模式约束或抽象边界
- 代码上下文或影响面备注
