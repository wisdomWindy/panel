# 获取媒体元数据

-   需要应用单独权限

## 接口说明

-   使用资源唯一ID查询对应资源的详细信息

## 接口地址

`/xlive/open-platform/v2/music/meta/list`

## 请求方式

POST

## 请求头

对POST请求增加公共请求头（Request Header），详情请查看 接口签名说明 文档

## 请求参数

-   url参数

无

-   body参数

| 参数名 | 必传 | 类型 | 备注 |
| --- | --- | --- | --- |
| metadata\_ids | true | string | 需要查询的资源id |
| code | true | int | 主播身份码 |
| app\_id | true | int | 应用的app\_id |

## 响应参数

-   body参数

| 参数名 | 必传 | 类型 | 备注 |
| --- | --- | --- | --- |
| infos | true | Object | 固定数据结构 |

infos结构体如下：

| 参数名 | 必传 | 类型 | 备注 |
| --- | --- | --- | --- |
| mapKey | true | Object | 固定数据结构 |

mapKey结构体如下：

| 参数名 | 必传 | 类型 | 备注 |
| --- | --- | --- | --- |
| metadata\_id | true | string | 资源ID |
| title | true | string | 歌曲标题 |
| artist\_name | true | int | 歌手名称 |
| album | true | int | 专辑名称 |
| cover\_url | true | string | 封面图片素材地址 |
