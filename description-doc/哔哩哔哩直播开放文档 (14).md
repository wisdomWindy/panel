# 获取媒体资源信息

-   需要应用单独权限

## 接口说明

-   使用资源唯一ID获取对应媒体资源详细信息

## 接口地址

`/xlive/open-platform/v2/music/list`

## 请求方式

POST

## 请求头

对POST请求增加公共请求头（Request Header），详情请查看 接口签名说明 文档

## 请求参数

-   url参数

无

-   body参数

| 参数名 | 必传 | 类型 | 备注 |
| --- | --- | --- | --- |
| metadata\_ids | true | string | 需要查询的资源id |
| code | true | int | 主播身份码 |
| app\_id | true | int | 应用的app\_id |

## 响应参数

-   body参数

| 参数名 | 必传 | 类型 | 备注 |
| --- | --- | --- | --- |
| info | true | Object | 固定数据结构 |

info结构体如下：

| 参数名 | 必传 | 类型 | 备注 |
| --- | --- | --- | --- |
| mapKey | true | Object | 固定数据结构 |

mapKey结构体如下：

| 参数名 | 必传 | 类型 | 备注 |
| --- | --- | --- | --- |
| transcode\_resources\_info | true | List | 资源详细信息 |

transcode\_resources\_info结构体如下

| 参数名 | 必传 | 类型 | 备注 |
| --- | --- | --- | --- |
| resource\_id | true | string | 资源列表 |
| transcode\_url | true | string | 转码链接 |
| duration | true | int | 时长（微秒） |
| size | true | int | 资源大小 |
| format | true | string | 码率格式 |
