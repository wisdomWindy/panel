# 获取已授权用户的union\_id信息

Scope: `USER_INFO` 需要申请权限 需要用户授权

## 接口说明

-   union\_id字段为该用户在您开发者权限下多应用的通用字段，只要开发者不改变，该字段不会变化
-   调用该接口可获取用户的union\_id字段

**重要:该接口需要根据业务需求单独申请开通**

## 请求URL

https://live-open.biliapi.com/v2/union\_id

## 请求方式

POST

## 请求头

请求增加公共请求头（Request Header），详情请查看 接口签名说明 文档

## 请求参数

-   url参数

    无

-   body参数

| 参数名 | 必传 | 类型 | 备注 |
| --- | --- | --- | --- |
| open\_id | 是 | string | 用户的唯一标识 |
| app\_id | 是 | int64 | 应用id |

## 响应参数

-   body参数

| 参数名 | 类型 | 备注 |
| --- | --- | --- |
| union\_id | string | 用户在同一个开发者下的唯一标识 |

-   响应样例

1.  `{`
2.      `"code": 0,`
3.      `"data": {`
4.          `"union_id": ""`
5.      `},`
6.      `"message": "",`
7.      `"request_id": "1922228763949772800"`
8.  `}`
