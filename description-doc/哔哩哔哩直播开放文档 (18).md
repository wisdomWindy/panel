# 哔哩哔哩创作者开放平台应用等级管理规则

## 概述

### 1.1 目的及依据

为鼓励开发行为，提升应用推广需求体验，平台推出应用等级制度，以给予应用推广的更多支持。现根据国家现行法律、法规、规章，以及  
《创作者开放平台服务协议》等平台规则与服务协议，特制订本应用等级管理规则（下称“本规则”）。

### 1.2 适用范围

本规则适用于哔哩哔哩直播开放平台与饭贩商店内通过审核并成功上架的应用。

### 1.3 应用等级定义

应用等级是平台根据应用的多个维度数据表现，反映应用在平台的综合能力，平台将给予不同的扶持。

## 应用等级实施细则

### 2.1 应用等级构成

#### 2.1.1 等级划分

应用等级分为5个级别（D~S），等级越高，则应用有权限申请获得推广能力支持越强。

#### 2.1.2 评级要求

平台综合考核应用在平台的项目数据表现计算应用等级。应用等级默认，默认等级为D级。

#### 2.1.2 指标维度

-   营收能力
-   社区贡献力
-   影响力

### 2.2 应用等级展示

#### 2.2.1 更新周期

应用等级每月1日进行数据更新，根据应用上一个自然月的项目数据进行综合计算。  
数据更新可能存在延迟情况，实际更新具体以产品内通知为准。如遇延迟，请开发者耐心等待。

#### 2.2.2 展示场景

暂无展示位置，请各位开发者发送邮件至live-open@bilibili.com咨询  
或添加QQ群联系管理员了解当前等级

## 附则

##### 3.1 平台有权根据平台发展及运营管理需要，适时调整本规则，并在平台进行公示。本规则生效后，开发者继续使用平台服务的，视为认可并接受本规则内容

##### 3.2 本规则于2022年6月22日公示，于2022年6月29日发布并生效实施
