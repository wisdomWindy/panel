## 获取弹幕信息

-   当该直播间有人发送弹幕时触发

**CMD**：LIVE\_OPEN\_PLATFORM\_DM

**返回字段**：

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| uname | string | 用户昵称 |
| uid | int64 | 用户UID（已废弃，固定为0） |
| open\_id | string | 用户唯一标识 |
| union\_id | string | 用户在同一个开发者下的唯一标识(默认为空，根据业务需求单独申请开通) |
| uface | string | 用户头像 |
| timestamp | int64 | 弹幕发送时间秒级时间戳 |
| room\_id | int64 | 弹幕接收的直播间 |
| msg | string | 弹幕内容 |
| msg\_id | string | 消息唯一id |
| guard\_level | int64 | 对应房间大航海等级 |
| fans\_medal\_wearing\_status | bool | 该房间粉丝勋章佩戴情况 |
| fans\_medal\_name | string | 粉丝勋章名 |
| fans\_medal\_level | int64 | 对应房间勋章信息 |
| emoji\_img\_url | string | 表情包图片地址 |
| dm\_type | int64 | 弹幕类型 0：普通弹幕 1：表情包弹幕 |
| glory\_level | int | 直播荣耀等级 |
| reply\_open\_id | string | 被at用户唯一标识 |
| reply\_uname | string | 被at的用户昵称 |
| is\_admin | int | 发送弹幕的用户是否是房管，取值范围`0或1`，取值为`1`时是房管 |

## 跨房弹幕信息

-   当该直播间为支持跨房弹幕的直播间模式，其他直播间有人发送弹幕时触发

**请注意**：除下面列出来的字段外，该cmd推送消息中的其他信息不保证可用性，并且推荐和直播间观众观看内容表现一致：**【不显示发送人信息】**

**CMD**：LIVE\_OPEN\_PLATFORM\_DM\_MIRROR

**返回字段**：

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| timestamp | int64 | 弹幕发送时间秒级时间戳 |
| room\_id | int64 | 当前收到这条弹幕的直播间 |
| msg | string | 弹幕内容 |
| msg\_id | string | 消息唯一id |
| emoji\_img\_url | string | 表情包图片地址 |
| dm\_type | int64 | 弹幕类型 0：普通弹幕 1：表情包弹幕 |

> 参考json

1.  `{`
2.    `"cmd": "LIVE_OPEN_PLATFORM_DM_MIRROR",`
3.    `"data": {`
4.      `"room_id": 1, //当前收到这条弹幕的直播间`
5.      `"msg": "", //弹幕内容`
6.      `"msg_id": "", //消息唯一id`
7.      `"timestamp": 0, //弹幕发送时间秒级时间戳`

11.  `}`

**请注意：如果单个直播间每秒进入人数超过R个人，那么会被限制每秒推送数量，其中R由当前服务的负载动态决定(最低不会低于`10 QPS`)**

**CMD**：LIVE\_OPEN\_PLATFORM\_LIVE\_ROOM\_ENTER

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| room\_id | int64 | 发生的直播间 |

| timestamp | int64 | 发生的时间戳 |

## 关于退出房间

由于没有明确的退出事件触发和标志，在**包括但不限于**以下情况都下可能会触发“退出房间”事件：

-   标签页后台挂起，被浏览器冻结或终止。
-   直播间检测到无响应（确认弹窗超时）后主动断开连接。
-   网络不良导致的断续重连。
-   关闭直播间后服务器推送消息超时。
-   其他未列出的情况

以上这些情况通常在服务器异步调用情况下被发现是连接不可达，系统会猜测用户已退出房间。因此，在数据不可信且存在大量重复无意义数据的情况下，未提供明确的退出房间事件。

## 消息推送结束通知

-   当目前长连接停止推送时触发

**当收到该CMD消息后则代表对应的game\_id已失效，不会再收到消息推送。失效的原因一般是由于心跳过期或者主动调用END等错误，具体错误请开发者监听API和心跳返回信息。**

**CMD**：LIVE\_OPEN\_PLATFORM\_INTERACTION\_END

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| game\_id | string | 结束消息推送的game\_id |
| timestamp | int64 | 发生的时间戳 |

1.  `{`
2.      `"cmd": "LIVE_OPEN_PLATFORM_INTERACTION_END",`
3.      `"data": {`
4.          `"game_id": "f0423922-60e9-4f8c-b5f3-6ad2cb888a22",`
5.          `"timestamp": 1714113037`
6.      `}`
7.  `}`
