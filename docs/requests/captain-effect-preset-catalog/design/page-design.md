# 页面设计：上舰特效内置模板

## 产品内容白名单

| 内容/交互 | 来源 |
| --- | --- |
| 特效模板下拉选择 | PRD 9.6.3、9.6.4 |
| 至少 10 个预设 | PRD US-005、9.6.4 |
| “金色尊享”选项 | PRD 9.6.3，U1 |
| 切换模板后应用模板默认配色 | U1 的“特效模板”实用目标，PRD US-005 的预设+自定义配色 |
| 保存、预览、重置、配色控件 | PRD 9.6.3-9.6.5，现有页面 |

## 用户旅程

1. 主播进入“上舰特效”，页面加载已保存配置和内置模板目录。
2. 主播展开“特效模板”，按显示名选择一个模板，包括“金色尊享”。
3. 选择后草稿的主色/副色立即更新为模板默认值；主播可继续手动微调。
4. 主播点击“预览”确认特效结构、配色和动效，然后保存。
5. 加载或预览失败仍使用现有稳定错误区域/消息；本次不新增反馈类型。

## 信息架构与布局

- 保留页头标题与“预览 / 重置默认 / 保存”操作区。
- 保留左侧“视觉与位置”、右侧“声音与连续触发”的现有分组。
- 模板选择仍是视觉区第一项，下游的主/副色是对当前模板的可编辑覆盖。
- 删除 `presets.length < 10` 时的“完整素材尚未提供”警告；完成后目录本身满足数量要求，该警告不再代表有效状态。

## 视觉与交互方向

- 配置页继续使用 Element Plus `el-select`，不新增卡片、图片资产或浮层选择器。
- 模板差异在独立特效窗口的 Canvas 中呈现：保留信息带基础结构，用颗粒、光芒、边框或背景装饰的组合区分主题。
- 颜色仍来自用户最终草稿，模板不用硬编码色覆盖已保存的自定义色。
- 动画保持 Canvas 单循环，尊重 `prefers-reduced-motion`；减少动效时显示稳定完整帧。

## 状态与反馈

- 加载：沿用 `v-loading` 和禁用模板下拉框。
- 已保存旧 ID：保留页面现有兼容选项，不丢失或自动重写用户配置。
- 切换模板：同步更新 ID 与目录默认色，不自动保存；保存仍需用户明确点击。
- 成功/失败：沿用现有保存 toast、预览错误 toast 和页面错误区。
- 重置：继续恢复 `captain-default` 的兼容默认配置。

## 响应式、可访问性与可用性

- 不改动现有单列/双列响应式断点，选项文字必须在选择器宽度内可读。
- 使用语义化选择器的原生键盘路径，不使用仅颜色可见的模板名。
- Canvas 仍为 `aria-hidden`，现有 `aria-live` 文本传达上舰事件内容；模板差异不改变事件语义。
- 所有模板仍保持足够的文字对比度，不依赖动画才能读取用户名。

## Tailwind 与组件边界

- 配置页如需样式变更只使用可审阅的 Tailwind CSS-style utility classes；不将 class 字符串藏入常量或 computed。
- `captain-effect/index.vue` 的模板选择仅一个生产调用方，且只需一个局部变更处理器：决策为 `keep inline`。
- `CaptainEffectSurface.vue` 已是具有 Canvas 生命周期的独立业务表面：继续复用，不拆出单模板组件，避免单调用方的透传层。

## UX 风险与缓解

- 风险：用户手工改色后误以为再切换模板会保留旧色。缓解：切换模板是明确的风格选择，同步带入该模板默认色；此后手工配色仍有效。
- 风险：已保存的未知 ID 从下拉框消失。缓解：保留当前 ID 的兼容选项与 Canvas 默认渲染分支。
- 风险：特效装饰影响帧率或文字清晰度。缓解：使用有上限的少量 Canvas 几何图形，文字层始终在装饰层之后绘制。

## 未决 UI 问题

无阻塞项。其他模板的名称与配色细节按用户“多内置几个”的明确授权作为保守本地主题提供，不声称 PRD 已规定其具体命名。
