# 请求：补齐上舰特效内置模板

## 请求标识

`captain-effect-preset-catalog`

## 来源

用户在 2026-09-22 直接反馈，并指向仓库 PRD 中的上舰特效要求。

## 目标

上舰特效页不再只显示 `captain-default`，而是提供至少 10 个可选内置模板，其中包含 PRD 明示的“金色尊享”；选择模板后预览和实际上舰弹窗展示与该模板对应的视觉特征。

## 初始完成信号

- 模板下拉框至少有 10 个内置选项，包含“金色尊享”。
- 从模板目录选择项目时，应用该模板的默认主色和副色，仍允许用户随后自定义配色。
- 预览与真实事件继续走现有 `CaptainEffectConfig` 链路，并按 `presetId` 呈现可区分的模板视觉。
- 旧的 `captain-default` 已保存配置仍可加载、保存和预览。

## 影响区域

Rust media IPC 特效模板目录、renderer media contract/adapter、上舰特效配置页与 Canvas 特效表面。

## 人工交接点

交付精准变更文件、自动化验证结果和可本地试用的开发服务地址。
