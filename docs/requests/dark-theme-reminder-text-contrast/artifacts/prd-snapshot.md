# 归一化缺陷快照

## 原文证据索引

- U1：“在深色主题下，图中红框中的内容看不清楚”。
- U2：“礼物提醒、礼物音效页面也有相同的问题”。
- U3：截图红框内是页标题、分区标题和声音类型行标签。

## 来源摘要

三个提醒配置页的部分文字只有浅色主题 `text-gray-*` 类，在深色背景下对比度过低。

## 关键业务目标

保留现有主次信息层级，使三个页面的已有内容在深色主题下清晰可读。

## 绿地脚手架敏感性

不适用；这是现有 Vue 页面的样式缺陷修复。

## 显式行为约束

- 仅在深色主题下改善文字与分隔线对比度。
- 保持浅色主题的原有 `text-gray-*` / `border-gray-*` 分支。
- 不改变内容、排版、控件和交互。

## 闭世界产品范围允许列表

- 三页已有主标题、描述、分区标题、标签、数值和统计文字的深色颜色状态。
- 三页已有分隔线的深色颜色状态。
- 相应的静态契约测试。

## 表单、表格、展示与交互

- 上舰特效：页标题、描述、两个分区标题、三个声音行标签与文件名。
- 礼物提醒：页标题、描述、开关标签、三组统计标签/数值和最近礼物标题。
- 礼物音效：页标题、描述、统计文字、全局音量标签、队列提示和表格中的文件名。
- 所有表单值、按钮、表格列和交互保持不变。

## 工作流与状态规则

主题状态继续由现有根节点 `.dark` 投影控制；本修复不增加状态或监听。

## 相关模块或页面

`captain-effect`、`gift-reminder`、`gift-sound`、`GiftSoundTable.vue`。

## 开放问题

无。
