## 业务摘要

深色主题下，上舰特效、礼物提醒和礼物音效页面的部分标题、分区标题、行标签和次要文字沿用浅色主题颜色，对比度不足。

## 目标

为三个页面中的现有文字层级和分隔线补充与项目现有规则一致的深色主题样式，保持浅色主题和业务交互不变。

- 上舰特效页红框所示页标题、分区标题和声音行标签在深色主题下清晰可读。
- 礼物提醒、礼物音效页的同类文字同步可读。
- 浅色主题样式、布局、功能、数据和交互不变。
- 回归测试、类型检查、Lint 和 Web 构建通过。
