# 礼物提醒位置与声音缺陷修复

## Source

当前 Codex 会话中的直接用户反馈。

## Goal

修复礼物提醒本地弹窗不遵循位置配置，以及勾选声音后测试/高价值礼物在无专属绑定时静默无声的问题。

## Done Signal

- 本地弹窗实际按左上、右上、左下、右下、居中显示并按配置时长消失。
- 测试提醒会产生本地弹窗事件；系统通知仍由操作系统决定位置。
- 声音开启时优先播放礼物专属绑定；没有可用绑定时播放内置提示音。
- 自动化、类型检查、Rust 测试和桌面打包通过。

## Non-Goals

不更改系统通知位置，不修改礼物音效绑定/导入导出语义，不重做提醒页面，不新增远端接口。
