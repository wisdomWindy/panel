# PRD快照：礼物音效系统API实现

## 来源
**文档路径**：用户提供的API接口信息
**快照时间**：2026-06-25

## 业务背景
礼物音效系统需要实现Bilibili API获取礼物列表功能。用户提供了实际的API接口信息，需要替换之前的模拟实现。

## 核心需求

### 1. 实现Bilibili礼物列表API调用
**需求描述**：使用实际的API接口获取礼物列表
**API接口**：https://api.live.bilibili.com/xlive/web-room/v1/giftPanel/roomGiftList
**优先级**：高
**验收标准**：
- 能够调用Bilibili API获取礼物列表
- 返回的礼物数据格式正确
- 处理API调用失败的情况

### 2. API参数说明
**必填参数**：
- room_id: 直播间长房间号（纯数字）
- platform: 固定填 web 或 pc

**可选参数**：
- area_parent_id: 直播一级分区ID，补齐能拿到活动限定礼物

### 3. 数据处理
**需求描述**：正确处理API响应和错误
**优先级**：高
**验收标准**：
- 解析API响应数据
- 转换为GiftInfo格式
- 处理各种错误情况

## 技术约束

### 现有架构
- 渲染进程服务：src/renderer/services/bilibili-gift-service.ts
- 主进程模块：src/main/modules/gift-sound/index.ts
- IPC通信：Electron IPC

### 依赖关系
- 依赖Bilibili开放平台API
