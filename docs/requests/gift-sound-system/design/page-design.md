# Page Design: 礼物音效配置页面

## Page Objective
为用户提供一个直观的界面来管理礼物音效配置，包括：
1. 查看和编辑礼物音效绑定
2. 上传和管理音效文件
3. 配置音效播放参数
4. 预览音效效果
5. 批量导入导出配置

## Target Users or Scenarios
**主要用户**：Bilibili直播主播
**使用场景**：
- 首次配置礼物音效系统
- 调整现有音效配置
- 测试新音效效果
- 批量管理多个礼物音效
- 导出配置备份或分享给其他主播

## Layout Structure
采用左右分栏布局：
- **左侧**：礼物列表和搜索区域（30%宽度）
- **右侧**：音效配置详情区域（70%宽度）

**顶部**：全局操作栏（导入导出、全局开关、批量操作）
**底部**：状态栏和快捷操作

## Visual Hierarchy
1. **一级元素**：礼物列表、音效配置表单
2. **二级元素**：音效预览控件、播放参数设置
3. **三级元素**：批量操作按钮、导入导出功能
4. **四级元素**：帮助信息、状态提示

## Section Breakdown

### 1. 全局操作栏
- 全局音效开关（一键开启/关闭所有音效）
- 导入配置按钮
- 导出配置按钮
- 批量操作下拉菜单（批量启用/禁用、批量删除）

### 2. 礼物列表区域
- 搜索框（按礼物名称或ID搜索）
- 礼物分类筛选（按价值、类型等）
- 礼物列表（显示礼物名称、当前绑定状态、启用状态）
- 添加新礼物按钮

### 3. 音效配置详情区域
- **礼物信息卡片**：显示礼物名称、ID、价值等基本信息
- **音效绑定区域**：
  - 音效文件选择器（支持拖拽上传）
  - 音效名称显示
  - 音效文件信息（大小、时长、格式）
- **播放参数设置**：
  - 音量滑块（0-100%）
  - 播放时长设置（完整播放/截取前N秒）
  - 播放模式选择（单次播放/循环播放）
  - 冷却时间设置（毫秒）
  - 优先级设置（数字越大优先级越高）
- **高级设置折叠面板**：
  - 淡入淡出效果开关
  - 淡入淡出时长设置
  - 静音时段设置（时间范围选择器）
- **操作按钮**：
  - 保存配置
  - 重置配置
  - 删除绑定

### 4. 音效预览区域
- 音效播放按钮
- 播放进度条
- 音量控制
- 播放/暂停/停止控制
- 播放状态指示器

### 5. 音效库管理
- 已上传音效文件列表
- 音效文件预览
- 音效文件删除
- 音效文件重命名

## Styling Direction
**设计风格**：现代简约风格，符合B站设计语言
**颜色方案**：
- 主色调：B站粉（#FB7299）
- 辅助色：深灰（#333333）、浅灰（#F4F4F4）
- 强调色：成功绿（#52C41A）、警告黄（#FAAD14）、错误红（#FF4D4F）

**字体**：
- 主字体：PingFang SC、Microsoft YaHei
- 代码字体：Monaco、Consolas

**间距**：
- 页面边距：24px
- 组件间距：16px
- 内边距：12px

**圆角**：
- 卡片圆角：8px
- 按钮圆角：4px
- 输入框圆角：4px

## Interaction Skeleton

### 1. 礼物选择交互
- 点击左侧礼物列表项，右侧显示对应配置
- 支持键盘导航（上下箭头选择）
- 支持搜索筛选

### 2. 音效上传交互
- 点击"选择文件"按钮打开文件选择器
- 支持拖拽文件到指定区域
- 上传进度显示
- 上传成功/失败反馈

### 3. 音效预览交互
- 点击播放按钮开始预览
- 拖动进度条跳转到指定位置
- 实时音量调节
- 播放状态实时更新

### 4. 配置保存交互
- 表单验证（必填项、格式检查）
- 保存确认对话框
- 保存成功/失败反馈
- 自动保存草稿（可选）

### 5. 批量操作交互
- 多选模式切换
- 批量选择确认
- 批量操作确认对话框
- 批量操作进度显示

## Responsive Behavior
**桌面端**（≥1200px）：左右分栏布局
**平板端**（768px-1199px）：上下分栏布局，礼物列表可折叠
**移动端**（<768px）：单列布局，通过标签页切换礼物列表和配置详情

**响应式断点**：
- 1200px：桌面端布局
- 768px：平板端布局
- 480px：移动端布局

## Design Risks
1. **音效文件大小限制**：大文件上传可能导致页面卡顿
   - 缓解措施：文件大小限制（10MB）、上传进度显示、异步处理
   
2. **音效预览性能**：同时预览多个音效可能导致音频冲突
   - 缓解措施：单次只允许预览一个音效、预览时暂停其他音频

3. **配置复杂性**：高级配置选项可能让新手用户困惑
   - 缓解措施：默认折叠高级选项、提供配置向导、添加帮助提示

4. **移动端体验**：小屏幕设备上配置表单可能过于拥挤
   - 缓解措施：响应式布局、分步配置、简化移动端界面

## Open UI Questions

2. 音效预览是否需要显示波形图？
3. 是否需要提供音效推荐库？
4. 批量导入导出的文件格式是JSON还是其他格式？
5. 是否需要配置版本历史记录？
6. 是否需要配置分享功能？
7. 是否需要配置模板功能？
8. 是否需要配置同步到云端功能？
