# 官网首页文档 Tailwind 化澄清记录

## 澄清 1：视觉目标

- **问题**：本次是否允许顺手做视觉重构？
- **结论**：不允许。本次要求尽量保持当前视觉效果，只做样式表达方式迁移。
- **影响**：实现阶段需要以“迁移 `<style>` 到 Tailwind”为目标，而不是重设计页面。

## 澄清 2：改造范围

- **问题**：是否需要同时处理静态资源和构建产物中的内联样式？
- **结论**：不需要。
- **影响**：
  - `.vitepress/dist` 不进入改造范围；
  - `public/logo.svg` 中的 `style` 属性不处理；
  - 仅改 Markdown / `.vitepress` / 必要配置。

## 澄清 3：页面覆盖范围

- **问题**：是否需要全站逐页迁移？
- **结论**：不需要。当前源码中真实存在 `<style>` 的页面只有首页和下载页，本次只处理这两页。
- **影响**：避免把需求扩散为整站重构。

## 澄清 4：样式供应链方向

- **问题**：是继续保留局部 CSS，还是正式接入 Tailwind？
- **结论**：正式接入本地 Tailwind 供应链。
- **影响**：需要在 `.vitepress/theme` 下新增样式入口，并以 `homepage:build` 验证接线。
