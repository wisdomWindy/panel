# 缺陷来源

## 来源系统

当前 Codex 会话中的直接用户反馈。

## 来源范围

`bilibili-live-tool` 免费版桌面应用。

## 缺陷标识

`i18n-tts-effect-window-fixes`

## 标题

业务页面国际化不完整、TTS 默认与反馈缺失、上舰特效窗口几何配置失效。

## 已观察行为

1. 切换 English 后只有菜单变为英文，其他页面仍显示中文。
2. 语音播报音色未默认选中 Microsoft HuiHui。
3. 点击语音播报“重置默认”后没有成功/失败提示。
4. 上舰特效弹窗尺寸无法在页面配置。
5. 上舰特效弹窗与所选位置不一致，例如选择居中却显示在左上角。

## 期望行为

1. English 应覆盖免费版可达业务页面及其用户可见子组件。
2. 未保存音色且 Microsoft HuiHui 可用时默认选中它。
3. 重置默认形成可观察的保存结果反馈。
4. 页面提供特效窗口宽高配置并持久化。
5. 窗口按所选主显示器位置展示。

## 复现线索

- 系统设置中切换 English 后依次打开各导航页面。
- 打开语音播报页并检查音色下拉框，随后点击重置默认并确认。
- 在上舰特效页选择居中并预览。

## 受影响模块或页面

免费版路由页面及其 live-data/media 子组件、语音播报页、上舰特效页、Tauri 特效窗口。

## 可用截图、日志或评论

本轮未提供截图或日志；用户给出了稳定、可直接复现的行为描述。

## 闭集修复范围

- 补齐免费版导航可达页面和直接子组件的中英文界面文案绑定。
- 在 TTS 未选择音色时优先解析 Microsoft HuiHui。
- 将 TTS 重置改为持久化操作并提供成功/失败反馈。
- 为 CaptainEffectConfig 增加窗口宽高并在页面配置、IPC、持久化与窗口创建链路中传递。
- 按主显示器可用几何信息计算并设置五种位置。
- 为上述行为补充测试和兼容默认值。

## 开放问题与缺失上下文

无阻塞项。宽高默认沿用现有 `560×280`；宽高上下限作为防止不可用窗口的技术约束，不扩展额外产品能力。
