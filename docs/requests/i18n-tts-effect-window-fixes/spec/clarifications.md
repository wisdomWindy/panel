# 规格澄清

## 已定决策

- 国际化覆盖免费版导航可达页面、仍可直接访问的基础页面及其现有直接子组件；不把用户内容翻译为英文。
- 窗口宽高默认沿用现有 `560×280`，单位 logical px。
- 允许范围为宽 `320..1920`、高 `180..1080`，属于防止不可用窗口的技术安全约束。
- 窗口位置以主显示器为基准并保留 24px 边距。
- HuiHui 只在无用户选择时作为首选，不覆盖已保存 voiceId。

## 缺失来源

无阻塞项。

## 范围外

- 自动翻译业务数据、日志正文、用户名或用户自定义 TTS 模板。
- 新增语言、云 TTS 服务或声音安装功能。
- 选择具体显示器、拖拽定位、百分比尺寸或多窗口布局。
- 重构整个 media 模块或引入代码生成。
