# 排行榜页面设计

## 页面概述

在现有直播数据看板（Dashboard）基础上，新增排行榜区域，展示本场直播的送礼榜、弹幕榜和舰长贡献榜。

## 视觉层次

### 排名样式
- 前三名使用特殊样式：🥇（金色）、🥈（银色）、🥉（铜色）
- 其他排名使用普通数字显示

### 数据展示
- 用户名：左对齐，字体大小 14px
- 数值：右对齐，字体大小 14px，使用等宽字体
- 表头：灰色背景，字体加粗

### 空状态
- 无数据时显示 `el-empty` 组件
- 提示文字："暂无排行榜数据"

## 交互设计

### Tab 切换
- 点击 Tab 切换排行榜类型
- 切换时无加载动画（数据已预加载）

### 数据更新
- 排行榜数据每 5 秒自动更新
- 更新时无闪烁，平滑过渡

### 响应式考虑
- 移动端：排行榜区域全宽显示
- 桌面端：排行榜区域与图表区域保持一致宽度

## 样式方向

- 使用 Tailwind CSS 实现所有样式
- 不使用 `<style>` 标签
- 不使用行内样式
- 遵循现有 Dashboard 的设计风格

## 设计风险

1. **数据量问题**：如果直播时间很长，排行榜数据可能很多
   - 解决方案：默认显示前 20 名，支持滚动查看更多

2. **性能问题**：排行榜数据更新频繁
   - 解决方案：使用防抖优化，避免频繁渲染

3. **舰长等级显示**：需要正确映射舰长等级名称
   - 解决方案：1=督察、2=提督、3=总督
