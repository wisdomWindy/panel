1. **类型定义位置**：将排行榜类型定义放在 `src/renderer/modules/recording/types.ts` 中，与现有录制类型保持一致。

2. **数据聚合位置**：将数据聚合函数放在 `src/renderer/stores/danmaku.ts` 中，因为数据来源于弹幕和礼物。

3. **组件结构**：使用 `el-tabs` 和 `el-table` 实现排行榜，与现有 Dashboard 风格保持一致。

4. **样式实现**：使用 Tailwind CSS 实现所有样式，不使用 `<style>` 标签。
