# 排行榜功能请求

## 请求 ID
`leaderboard`

## 请求类型
新功能开发

## 来源
PRD 文档 `docs/requirements/Bilibili_Live_Tool_PRD.md` 第 3.1 节

## 目标
实现直播数据看板中的排行榜功能，展示本场直播的送礼榜、弹幕榜和舰长贡献榜。

## 业务背景
当前直播数据看板已实现：
- ✅ 实时数据：展示当前在线人数、弹幕数量、礼物收入
- ✅ 趋势图表：绘制本场直播的人气曲线与收益曲线

但排行榜功能尚未实现，需要补充完成。

## 功能需求

### 1. 送礼榜
- 展示本场直播中送礼价值最高的用户列表
- 显示排名、用户名、送礼总价值（金仓鼠/舰长数）
- 支持按送礼价值排序

### 2. 弹幕榜
- 展示本场直播中发送弹幕数量最多的用户列表
- 显示排名、用户名、弹幕数量
- 支持按弹幕数量排序

### 3. 舰长贡献榜
- 展示本场直播中开通/续费舰长的用户列表
- 显示排名、用户名、舰长等级、贡献时间
- 支持按舰长等级和贡献时间排序

## 用户故事

| ID | 用户故事 | 验收标准 |
|----|----------|----------|
| US-LB-01 | 作为主播，我想要查看本场送礼榜，以便了解哪些观众最支持我 | 送礼榜实时更新，显示前 20 名用户 |
| US-LB-02 | 作为主播，我想要查看本场弹幕榜，以便了解哪些观众最活跃 | 弹幕榜实时更新，显示前 20 名用户 |
| US-LB-03 | 作为主播，我想要查看本场舰长贡献榜，以便感谢舰长支持 | 舰长榜实时更新，显示所有舰长 |

## 技术要求

- 排行榜数据基于本场直播会话，直播结束后重置
- 数据更新延迟 < 5 秒
- 支持空状态展示（无数据时）
- 使用 Tailwind CSS 实现样式，不使用 style 标签
