# 排行榜功能澄清记录

## 已解决的问题

### 1. 排行榜显示数量
**问题**：送礼榜和弹幕榜应该显示多少名用户？
**解决方案**：显示前 20 名用户，如果数据不足 20 名则显示全部。
**决策时间**：2026-06-17

### 2. 舰长贡献榜排序规则
**问题**：舰长贡献榜应该如何排序？
**解决方案**：按舰长等级降序（总督 > 提督 > 督察），同等级按贡献时间升序（先贡献的排在前面）。
**决策时间**：2026-06-17

### 3. 数据更新频率
**问题**：排行榜数据应该多久更新一次？
**解决方案**：每 5 秒更新一次，与现有 Dashboard 的数据更新频率保持一致。
**决策时间**：2026-06-17

### 4. 排名样式
**问题**：前三名应该如何显示？
**解决方案**：使用 emoji 图标（🥇🥈🥉）和特殊背景色（金色、银色、铜色）。
**决策时间**：2026-06-17

### 5. 空状态处理
**问题**：无数据时应该如何显示？
**解决方案**：使用 Element Plus 的 `el-empty` 组件，显示"暂无排行榜数据"提示。
**决策时间**：2026-06-17

### 6. 样式实现方式
**问题**：应该如何实现样式？
**解决方案**：使用 Tailwind CSS 实现所有样式，不使用 `<style>` 标签或行内样式。
**决策时间**：2026-06-17

## 设计决策

### 1. 使用 el-table 展示排行榜
**决策**：使用 Element Plus 的 `el-table` 组件展示排行榜数据
**原因**：
- 与现有 Dashboard 风格一致
- 支持排序、滚动等功能
- 易于维护和扩展

### 2. 使用 el-tabs 实现 Tab 切换
**决策**：使用 Element Plus 的 `el-tabs` 组件实现 Tab 切换
**原因**：
- 与现有 UI 风格一致
- 支持动画效果
- 易于使用和维护

### 3. 数据聚合方式
**决策**：在前端实时聚合排行榜数据
**原因**：
- 数据量较小（单场直播）
- 避免后端额外开销
- 实时性要求高

### 4. 组件位置
**决策**：在 Dashboard 页面底部新增排行榜区域
**原因**：
- 与现有图表区域保持一致
- 不影响现有布局
- 用户可以滚动查看更多内容
