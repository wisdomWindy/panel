# 直播录制功能

## 请求标识

- **request-id**: live-recording
- **创建时间**: 2026-06-16

## 来源

`docs/requirements/Bilibili_Live_Tool_PRD.md` 第 3.4 节「直播录制」。

## 业务摘要

为 Bilibili 直播助手提供直播流录制能力，支持全程录制和高光片段录制，满足主播内容存档、二次剪辑和内容复用需求。功能涵盖：全程录制（自动开始、格式选择、质量配置、分段录制、存储管理）、高光录制（自动触发、手动打点、片段提取、独立保存）、录制管理（列表展示、播放预览、文件操作、导出）、录制状态显示（状态栏指示、时长/大小实时显示、快捷操作）。

## 目标声明

在 Bilibili 直播助手中实现完整的直播录制功能，具体包括：

1. 用户可一键开始/暂停/停止直播流录制
2. 支持 MP4（H.264+AAC）和 FLV 格式输出
3. 支持选择录制质量（原始流质量 / 720p / 1080p）
4. 支持按文件大小或时长自动分段录制
5. 支持自定义存储路径、最大存储空间和自动清理策略
6. 当直播间热度激增（弹幕刷屏、高价值礼物、舰长赠送）时自动标记高光时刻
7. 支持快捷键（默认 F9）手动标记高光时刻
8. 自动提取高光时刻前后 N 秒的录制片段并独立保存
9. 在主界面状态栏实时显示录制状态、时长和文件大小
10. 提供录制文件列表，支持预览、重命名、删除、打开目录、导出操作
