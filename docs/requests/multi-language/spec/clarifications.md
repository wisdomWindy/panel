# 多语言支持 - 澄清记录

## 问题 1：语言切换是否需要实时生效

**问题**: 语言切换是否需要实时生效（无需重启）？

**回答**: 是，语言切换需要实时生效，用户选择语言后界面立即更新。

**最终决策**: 使用 vue-i18n 的 Composition API 模式，支持实时切换。

**影响规格区域**: vue-i18n 配置、设置页面

## 问题 2：是否需要支持自动检测系统语言

**问题**: 是否需要支持自动检测系统语言？

**回答**: 当前阶段不需要，用户手动选择语言。后续版本可考虑自动检测。

**最终决策**: MVP 阶段不实现自动检测，预留接口。

**影响规格区域**: 无

## 问题 3：后续是否需要扩展其他语言

**问题**: 后续是否需要扩展日语、韩语等其他语言？

**回答**: 是，后续可能需要扩展其他语言。

**最终决策**: 预留国际化接口，语言包结构支持扩展。

**影响规格区域**: 语言包结构设计

## 问题 4：Element Plus 组件库的多语言如何配置

**问题**: Element Plus 组件库的多语言如何配置？

**回答**: 使用 Element Plus 的 locale 配置，与 vue-i18n 同步。

**最终决策**: 在 main.ts 中配置 Element Plus 的 locale。

**影响规格区域**: main.ts 配置

## 问题 5：语言包 key 命名规范

**问题**: 语言包 key 命名规范是什么？

**回答**: 采用模块化命名，格式为 `模块.功能`，如 `nav.dashboard`、`common.save`。

**最终决策**: 遵循现有语言包的命名规范。

**影响规格区域**: 语言包结构

## 问题 6：是否需要支持语言包热更新

**问题**: 是否需要支持语言包热更新？

**回答**: 当前阶段不需要，语言包打包在应用内。

**最终决策**: 语言包静态打包，不支持热更新。

**影响规格区域**: 无
