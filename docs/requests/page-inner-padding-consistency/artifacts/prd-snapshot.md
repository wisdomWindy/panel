# 归一化需求快照

## Verbatim Source Evidence Index

- U1："上舰特效、礼物提醒、礼物音效、插件管理页面的边距与其他页面不一致，例如：图片中红框中部分的距离"

## 来源摘要与业务目标

统一四个点名页面与其他路由页面的内容起始位置，消除共享 shell padding 与 route 根节点 padding 的重复叠加。

## Greenfield Scaffold Sensitivity

不适用：既有 Vue/Tauri 应用的局部布局缺陷。

## 显式行为约束

- 只调整四个页面的根级外侧间距。
- `App.vue` 的响应式边距保持不变。
- 页内表单、表格、分栏、标题、按钮、状态、交互和主题保持不变。

## Closed-World Product Scope Allowlist

唯一授权的用户可见变化是四个点名页面的内容外侧距离与其他页面一致。无新字段、文案、控件、交互、默认值、校验、权限、导航、API/payload、状态映射或埋点。

## 表单、表格、展示与交互

所有既有内容原样保留；本次只移除 route 根节点重复 padding。

## 工作流与状态规则

导航进入页面 -> shell 提供统一响应式边距 -> 页面原有内容和状态照常工作。无状态流转变化。

## 相关页面与开放问题

相关页面：上舰特效、礼物提醒、礼物音效、插件管理。开放问题：无。
