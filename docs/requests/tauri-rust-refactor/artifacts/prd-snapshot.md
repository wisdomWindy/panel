## Source Summary

PRD 要求把现有 Electron 应用迁移成 Tauri v2 桌面应用。Vue WebView 仅承担 UI；Rust 负责网络、规则、持久化、录制、音频、AI 代理、插件沙箱、会员鉴权和模块下载。产品用相同数据目录交付免费/会员两个安装包，免费包在二进制和 UI 层均不得包含会员体系，会员包在运行时按会员状态控制模块。

## Key Business Goals

1. 保持全部既有免费/会员功能且体验不降级。
2. 降低资源消耗并提升 1000 条/秒事件负载下的稳定性。
3. 将文件、数据库、密钥、网络和 Sidecar 权限收敛到 Rust。
4. 确保 AI 仅由用户主动触发、仅本地预览，整个产品没有发送弹幕能力。
5. 让会员能力可下载、可暂停、可续费恢复，同时不影响免费底座。

## Greenfield Scaffold Sensitivity

- `greenfield_scaffold_sensitive=true`
- 新增运行面：`src-tauri` Rust crate、Tauri 配置、Capabilities、资源/Sidecar 配置和双通道构建。
- 保留现有 Vue/Vite 前端；不需要另建 Vue starter。
- 仓库发现：没有 `Cargo.toml`、`src-tauri`、Tauri sibling package 或仓库生成器。
- 官方候选：Tauri v2 CLI 支持向现有前端单独初始化 backend；这是与现有工程最匹配的 scaffold。
- spec 前待确认：CLI 初始化后的版本、插件、配置与 PRD 的双通道偏差清单。

## Explicit Behavior Constraints

### 全局与构建

- `source-backed`：主窗口默认 1280x800，最小 1024x680，可缩放和全屏；布局为顶部工具栏、左侧导航、中央内容区、底部状态栏。
- `source-backed`：免费包无会员按钮、登录按钮、会员中心、AI、刷屏防护、充值或升级引导，也无会员鉴权/模块下载代码路径。
- `source-backed`：会员包充值前仅增加登录/开通会员与会员中心；激活后显示 AI/刷屏防护和到期时间；到期后置灰会员能力并显示续费。
- `source-backed`：两个安装包应用标识符和数据目录相同，覆盖安装保留数据。

### 连接、事件与风控

- `source-backed`：`room_connect` 校验 1-20 位数字房间号，获取初始化信息并建立只读 WebSocket；断线每 5 秒重试，最多 10 次。
- `source-backed`：事件归一化为弹幕、礼物、舰长、进房；先经过身份、敏感词和黑名单处理，再推送 UI、TTS、AI 上下文与统计。
- `source-backed`：弹幕面板提供类型筛选、用户名/内容搜索、暂停滚动与仅清屏不删日志；时间为 `HH:mm:ss`。
- `source-backed`：敏感词使用精确/模糊规则，命中可屏蔽/替换/仅记录；导入失败事务回滚。
- `source-backed`：黑名单用户不展示、不播报、不统计；支持增删、搜索、导入导出。
- `source-backed`：自动禁言默认关闭，首次开启必须固定风险确认；仅会员激活且接口可用时执行，否则降级本地告警。

### 提醒、音频与录制

- `source-backed`：舰长特效独立透明无边框置顶窗口，停留默认 5 秒，多事件排队不重叠，支持 DPI/多屏。
- `source-backed`：礼物提醒支持阈值、通知/弹窗/音效、连击窗口、最近 20 条和本场统计。
- `source-backed`：礼物音效支持 MP3/WAV、单礼物音量/开关、全局音量、预览、批量导入导出和每秒至少 10 个队列吞吐。
- `source-backed`：TTS 优先级为舰长 > 礼物 > 房管 > 普通，支持系统/云端降级、模板变量白名单、暂停与清队列。
- `source-backed`：录制由 FFmpeg Sidecar 完成，支持 MP4/FLV、画质、分段、自动录制、高光前后 30 秒、F9、10GB 默认配额和 5GB 水位。

### 统计与导出

- `source-backed`：看板每 5 秒刷新在线、弹幕、速率、礼物、舰长和趋势；聚合统计永久保留。
- `source-backed`：排行榜每 10 秒更新送礼/弹幕/舰长榜，变动高亮 3 秒，支持 TOP10/20/50/100。
- `source-backed`：CSV 只能由系统对话框选择路径并由 Rust 写入，支持本场/今日/近 7 天/自定义。

### AI、会员与模块

- `source-backed`：AI 必须由用户点击生成，Rust 组装人设、弹幕、ASR 和人工输入，流式推送，过滤/截断后仅预览，无发送按钮或 Command。
- `source-backed`：ASR 首次启用必须展示模型名、大小、许可和来源，用户同意后断点下载并校验哈希。
- `source-backed`：会员状态为未登录、已登录未付费、激活、到期、续费恢复；令牌采用 Ed25519，默认离线有效 7 天。
- `source-backed`：支付成功后下载临时包、校验哈希、解压版本目录、写数据库并发送 `module_installed`；到期保留模块，续费版本一致时直接复用。
- `missing-source`：OAuth、支付、订单轮询、会员公钥、模块清单、下载地址和服务端 API 的生产端点与完整协议未在 PRD 给出。

### 配置、更新、插件和 i18n

- `source-backed`：配置使用 SQLite/Tauri Store，敏感值加密；导入在事务内，重置二次确认。
- `source-backed`：更新按免费/会员独立通道，支持灰度、黑名单、强制更新、签名、暂停与回滚；离线静默跳过。
- `source-backed`：插件使用独立 WASM 实例，仅通过宿主白名单读取脱敏事件；禁止直接数据库、密钥、文件和未声明网络。
- `source-backed`：中英文即时切换、首次跟随系统，Rust 错误码映射固定占位符，缺失回退中文。

## Workflow And State Rules Extracted From Source

1. 应用启动 -> 迁移/恢复配置 -> 判断构建通道 -> 会员包校验令牌 -> 恢复导航与服务 -> 用户连接房间。
2. 房间事件 -> Rust 解包 -> 敏感词/黑名单/身份 -> EventBus -> 日志/统计/TTS/提醒/前端；任何发送链路都禁止存在。
3. 会员购买 -> 登录 -> 下单/支付 -> 令牌验签 -> 模块下载/哈希/安装 -> 激活；失败保留免费底座。
4. 会员到期 -> 停止 AI/ASR/自动禁言和会员 Sidecar -> 推送到期 -> UI 置灰 -> 模块保留；续费后校验版本并直接恢复或更新。
5. 录制 -> 校验路径/水位 -> 启动 Sidecar -> 持续状态/高光 -> 停止/落库；空间不足必须主动停止。
6. 数据迁移 -> 备份 -> 空间检查 -> 事务迁移 -> 成功保留最多 3 个备份；失败回滚。

## Data And Security Contract Snapshot

- SQLite：`t_account`、`t_membership`、`t_order`、`t_module`、`t_ai_config`、`t_ai_log`、`t_room_config`、`t_sensitive_word`、`t_black_user`、`t_gift_sound`、`t_live_stat`、`t_app_setting`、`t_event_log`、`t_recording`、`t_highlight`、`t_plugin`、`t_tts_config`、`t_asr_config`、`t_moderate_config`、`t_ranking_archive`、`t_schema_state`。
- 索引：事件/AI 日志的房间时间、直播统计房间日期、黑名单 UID、敏感词分类、榜单房间日期、订单用户时间。
- 参数：room/UID 1-20 位数字；用户名 1-50；敏感词 1-100；音量 0-1；阈值非负；时间/套餐/模块/模板变量均白名单。
- 路径：只能使用系统对话框授权并持久化的路径；模块目录由 Rust 独占管理。
- effect window Capability 无 Command 权限，仅监听 Rust 事件。
- 免费包不注册 `membership_purchase`、`ai_generate`、`moderate_mute`、`asr_start`、`membership_orders`、`module_update`。

## Acceptance And Regression Baseline

- 关键性能：冷启动 <=2 秒、空闲内存 <=120MB、录制+AI <=200MB、CPU 增量 <=15%、事件延迟 <100ms、AI 总延迟 <=5 秒。
- 关键可靠性：连接 >99%、10 次断网重连成功率 >=95%、统计/身份/黑名单准确率按 PRD 目标、24 小时持续记录。
- 关键安全：路径/参数校验、会员验签、插件隔离、敏感配置不可由前端/插件读取、更新/模块签名校验。
- 关键回归：现有连接、弹幕、礼物、黑名单、TTS、录制、AI、插件、多语言、日志和设置能力迁移后仍可用。

## Notable Open Questions

- `external-interface-pending`：会员服务、OAuth、支付、模块 CDN/manifest、更新通道、B 站 Cookie 管理接口没有生产契约或凭据。
- `external-artifact-pending`：FFmpeg LGPL shared 二进制、whisper.cpp 二进制/模型清单、签名公钥和许可文本没有随仓库提供。
- `source-ambiguity`：PRD 第 5.3 节模块目录示例括号不完整；规范化为 `modules/<module_name>/<version>/`，不改变产品语义。
- `source-conflict`：第 12 节文字称“17 张表”，SQL 实际列出 21 张表；下游以显式 SQL 表清单为准并记录该文档缺陷。
- 上述外部项不阻止本地架构、接口、模拟/受控降级与公共功能实现，但阻止声称真实支付、真实会员签发、真实模块 CDN 和全部 Sidecar 分发已经可生产上线。
