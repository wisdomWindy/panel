# 请求: 整体 UI 样式与布局优化

## 基本信息

- **请求 ID**: ui-layout-improvement
- **创建日期**: 2026-06-12
- **来源**: 用户直接需求（本地需求，非 PRD 来源）
- **需求描述**: 调整页面样式和布局，使布局间距合理，样式美观符合人眼视觉观赏

## 描述

对 Bilibili 直播助手项目的全部页面进行 UI 样式和布局优化，提升视觉美观度和用户体验。

### 当前页面清单

| 页面 | 文件 | 当前状态 |
|------|------|---------|
| 整体布局 | App.vue | el-header + el-aside + el-main 基础布局，header 简单蓝色 |
| 登录页 | Login.vue | 居中表单，bg-gray-100 背景 |
| 仪表盘 | Dashboard.vue | el-row/el-col 网格，el-card 包裹统计 + 图表 |
| 连接配置 | Connection.vue | 简单表单 + 连接信息描述列表 |
| 弹幕池管理 | DanmakuPool.vue | 左右分栏：表格 + 自动发送控制面板 |
| 弹幕列表 | DanmakuList.vue | 统计数据行 + 弹幕卡片列表 |
| 设置 | Settings.vue | 左侧菜单 + 右侧表单的左右分栏 |
| 黑名单管理 | Blacklist.vue | 表格 + 弹窗表单 |
| 特效预览 | EffectPreview.vue | 左侧参数配置 + 右侧 Canvas 预览 |

### 改进方向

1. **整体布局**: header 颜色过渡更精致，侧边栏图标与文字间距
2. **卡片间距**: 统一卡片之间的间距，使用更一致的 gap 体系
3. **颜色体系**: 使用更舒适的视觉颜色，引入渐变和阴影提升层次感
4. **统计卡片**: StatCard 组件增加图标、颜色指示、悬停效果
5. **表格样式**: 优化表格的留白与边框样式
6. **表单布局**: 统一表单项目间距和标签宽度
7. **响应式优化**: 确保各分辨率下布局合理
