# 澄清记录: UI 样式与布局优化

## 已解决的决策

### D1: 配色方案选择

**问题**: 用户未指定具体配色方案
**决策**: 采用 Element Plus 原生蓝色系为主色，侧边栏使用行业标准的深色侧边栏 (#304156)，header 使用深蓝渐变，与 B 站品牌调性一致
**理由**: Element Plus 默认主题色作为基准，深色侧边栏是现代后台管理系统的常见实践

### D2: 侧边栏样式

**问题**: 是否保留浅色侧边栏
**决策**: 改为深色侧边栏 (#304156)，白色菜单文字，激活态 Element Plus 蓝色
**理由**: 深色侧边栏提供更强的视觉层次感，区分导航区与内容区

### D3: 间距统一标准

**问题**: 各页面使用 `mt-5` (20px) 还是其他间距
**决策**: 统一为 `mt-4` (16px) 作为行间距 + `gutter="20"` 作为列间距
**理由**: 16px 是 4px 网格体系的基准间距，视觉上更舒适

### D4: 背景色

**问题**: 页面主背景色选什么
**决策**: 统一使用 `#F0F2F5`，登录页、仪表盘等所有页面
**理由**: 浅灰背景可以衬托白色卡片，形成视觉层次

### D5: 弹幕卡片颜色方案

**问题**: 收到弹幕和已发送弹幕的视觉区分
**决策**: 收到弹幕：蓝色左边框 + 浅蓝背景；已发送弹幕：绿色左边框 + 浅绿背景
**理由**: 蓝绿对比明显且符合直觉（蓝=接收，绿=发出）
