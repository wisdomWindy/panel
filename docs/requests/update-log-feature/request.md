# 更新日志功能

## 请求标识

- **request-id**: update-log-feature
- **创建时间**: 2026-06-16

## 来源

`docs/requirements/Bilibili_Live_Tool_PRD.md` 第 3.4 节「更新日志与版本管理」。

## 业务摘要

在应用内实现版本更新检测与更新日志查看能力，使用户无需离开应用即可了解产品迭代内容。功能包括：启动时自动检测新版本、菜单入口查看历史更新日志、版本变更后首次启动展示"新版本特性"弹窗、状态栏更新提示图标。当前阶段不支持应用内自动安装更新，仅跳转至下载页面。

## 目标声明

在 Bilibili 直播助手中实现完整的更新日志功能，具体包括：

1. 用户可通过菜单栏「帮助 → 更新日志」查看历史版本变更记录
2. 应用启动时自动检测新版本（可在设置中关闭）
3. 版本变更后首次启动展示"新版本特性"弹窗
4. 检测到新版本时在状态栏显示提示图标

## 初始完成信号
