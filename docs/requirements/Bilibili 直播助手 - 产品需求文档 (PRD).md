## 1\. 产品概述

### 1\.1 产品愿景

打造一款集观众弹幕监控、智能观测、特效展示、直播录制于一体的 Bilibili 直播辅助工具，帮助主播降低直播运营成本，实时掌握直播间观众互动情况，同时满足内容存档和二次创作需求。

产品功能分层明确，区分免费基础能力与会员增值能力：

1\. 免费基础功能：纯直播间只读数据监听、本地提醒、直播录制、数据统计、风控管理、弹幕语音播报，**无任何自动发送弹幕能力**，合规无风险；

2\. 会员专属功能：AI文案辅助系统，支持自定义人设、结合直播间上下文生成本地回复建议与摘要，所有结果仅在工具内预览，不主动发送至直播间。

### 1\.2 目标用户

- Bilibili 全职/兼职游戏、娱乐、虚拟主播

- 直播间运营团队成员，负责直播复盘、互动运营

- 需要24小时无人值守挂机监控、维持直播间基础互动的虚拟主播、挂机直播间运营者

## 2\. 用户研究

### 2\.1 用户画像

#### 用户画像 A：全职主播小王

**基本信息**: 28岁，全职游戏主播，每天直播 8 小时

**痛点**:

- 直播时需要同时关注弹幕、操作游戏，分身乏术，无法兼顾所有观众互动

- 夜间挂机直播无人值守，无法回应观众弹幕，直播间氛围冷清

- 容易错过舰长开通、大额礼物等高价值互动事件

- 人工逐条回复弹幕效率极低，无法维持持续互动

**期望**:

- 舰长、大额礼物触发本地弹窗\+音效提醒，不错过高价值互动

- 直播时由AI生成本地回复建议，降低人工组织话术的负担

- 自动播报弹幕、完整记录直播数据，方便赛后复盘

#### 用户画像 B：运营者小张

**基本信息**: 25岁，直播账号运营，负责互动策划、内容复盘

**痛点**:

- 人工统计弹幕热度、送礼数据，复盘效率低下

- 观众高频重复问题无法统一答疑，互动体验差

- 缺少高光时刻自动记录、直播内容存档工具

- 多场次直播人工回复工作量大，话术风格无法统一

**期望**:

- AI辅助归纳观众高频问题并生成本地答疑建议

- 自定义AI人设，统一直播间互动话术风格

- 自动录制直播内容、标记高光时刻，方便二次剪辑创作

- 可视化数据看板，辅助直播运营策略优化

#### 用户画像 C：兼职主播小李

**基本信息**: 22岁，大学生，兼职直播，每周直播3\-4次

**痛点**:

- 不熟悉B站直播协议，无法集中查看全量观众弹幕

- 无免费直播数据统计工具，复盘难度高

- 预算有限，仅按需解锁高端增值功能

**期望**:

- 免费使用直播间监控、弹幕播报、数据复盘基础功能

- 工具轻量化、上手零成本

- 按需开通会员，解锁AI文案辅助能力

### 2\.2 用户场景

#### 场景 1：夜间挂机直播监控（免费基础功能）

**背景**: 主播休息，直播间挂机运行，工具仅做数据监听与本地提醒

**流程**:

1. 主播连接直播间，开启弹幕语音播报、礼物/上舰提醒功能

2. 配置敏感词过滤、自动禁言规则，维护直播间秩序

3. 工具后台静默监听直播间全量事件，无任何主动操作

4. 观众发送弹幕，工具本地展示、语音播报、留存日志

5. 触发舰长、大额礼物事件，工具弹窗\+音效提醒

6. 主播次日通过数据看板、日志复盘整场直播数据与互动情况

#### 场景 2：AI回复建议生成（会员专属功能）

**背景**: 主播直播过程中，开通会员使用AI生成符合人设的本地回复建议

**流程**:

1. 主播提前配置AI人设、模型参数、敏感词和上下文范围

2. 主播在工具内输入问题或选择已有上下文，主动发起文案生成

3. AI结合上下文与人设生成回复建议

4. 生成结果经过敏感词过滤后仅在工具内展示

5. 主播可重新生成或调整输入，不产生直播间发送副作用

6. AI生成、拦截和失败记录可留存日志，支持复盘导出

#### 场景 3：高光时刻自动录制（免费基础功能）

**背景**: 主播进行高难度游戏挑战，需要自动捕捉精彩瞬间

**流程**:

1. 系统实时监测直播间弹幕热度、礼物波动数据

2. 检测到弹幕激增、热度暴涨，自动判定为高光时刻

3. 自动录制高光前后30秒片段，独立保存为MP4文件

4. 主播也可通过F9快捷键手动标记高光时刻

5. 直播结束后，主播可手动剪辑、上传高光片段至B站

#### 场景 4：舰长开通专属特效提醒（免费基础功能）

**背景**: 观众首次/续费开通舰长，主播需要醒目提醒

**流程**:

1. 工具监听直播间舰长开通事件，识别首次开通/续费类型

2. 本地独立窗口弹出专属金色视觉特效，播放定制欢迎音效

3. 本地日志记录感谢文案，仅工具内展示，不对外发送弹幕

4. 特效停留5秒后自动淡出，不影响直播画面

#### 场景 5：全场直播存档录制（免费基础功能）

**背景**: 重要直播场次，需要全程存档用于后期复盘与二次创作

**流程**:

1. 主播连接直播间后，手动开启全程录制功能

2. 工具实时拉取直播流，无损录制并实时标记高光节点

3. 直播结束后停止录制，自动生成完整录播文件与独立高光片段

4. 主播可本地预览、剪辑、手动上传至B站平台

## 4\. 功能详细需求

### 4\.1 直播间连接与弹幕接收（免费）

**功能描述**: 通过 WebSocket 全量连接 Bilibili 直播间，实时接收观众弹幕流、直播间各类事件流，毫秒级同步展示在本地面板，**仅做只读接收，无任何主动发送、操作直播间权限**。

#### 核心功能

- **实时流接收**: WebSocket全量拉取直播间弹幕、礼物、舰长、进房事件，毫秒级同步本地展示

- **弹幕完整展示**: 按时间顺序展示弹幕，包含用户名、用户等级、弹幕内容、时间戳、粉丝勋章信息

- **自动重连机制**: 网络断开后自动重试重连（最多10次，间隔5秒），缓存断连期间数据，重连后补全展示

- **多房间监听**: 支持同时监听多个直播间事件流，独立分区展示数据

#### 功能规格

**输入**: 有效B站直播间号、开放平台连接凭证

**输出**: 本地弹幕面板实时展示、本地日志持久化记录

**前置条件**: 网络正常、直播间状态有效、开放平台鉴权正常

**后置条件**: WebSocket长连接稳定运行，事件流持续接收无中断

#### 异常处理

- 网络断开：自动重试重连，缓存断连数据，重连后补全

- 直播间无效：弹窗提示错误，终止连接流程

- 开放平台鉴权失效：提示用户检查连接凭证

- 高并发弹幕：自动限流，优先展示高等级用户弹幕，保证界面流畅

#### 验收标准

弹幕接收延迟＜100ms、连接成功率＞99%、自动重连成功率＞95%、支持1000条/秒高并发弹幕处理

#### 核心功能

- 精准识别房管、总督、提督、舰长、大会员、普通观众身份

- 差异化颜色标签展示，直观区分用户层级

- 展示用户粉丝勋章名称、等级信息

- 支持按用户等级优先级排序弹幕展示

### 4\.3 敏感词过滤（免费）

**功能描述**: 内置分级敏感词库，支持自定义词汇，自动拦截违规、广告、引战弹幕，屏蔽展示与语音播报，完整留存过滤日志。

#### 核心功能

- 支持精确匹配、模糊匹配双重过滤规则

- 命中敏感词弹幕自动屏蔽，不展示、不播报

- 分类记录过滤日志，留存用户、内容、时间信息

- 支持词库自定义新增、删除、批量导入导出

#### 敏感词分类

违禁违法词汇、广告引流词汇、人身攻击引战词汇、用户自定义屏蔽词汇

#### 验收标准

过滤准确率100%、过滤延迟＜10ms、支持万级词库、误判率＜1%

### 4\.4 自动禁言与刷屏防护（免费）

**功能描述**: 基于频率、重复度、相似度规则识别刷屏违规用户，调用B站官方开放接口执行禁言操作，自动维护直播间秩序。

#### 核心功能

- 多维刷屏检测：频率、重复内容、高相似度内容识别

- 自定义禁言时长：10分钟/1小时/永久禁言

- 支持批量选中用户一键禁言

- 全量禁言操作日志留存，可溯源查询

#### 刷屏检测规则

- 频率违规：10秒内同一用户发送＞5条弹幕

- 重复违规：1分钟内发送＞3条完全相同弹幕

- 相似违规：1分钟内发送＞5条相似度＞80%弹幕

#### 验收标准

刷屏检测准确率＞95%、禁言响应＜2秒、执行成功率＞98%、误判率＜3%

### 4\.5 黑名单管理（免费）

**功能描述**: 本地独立黑名单库，支持手动/自动添加违规用户，永久屏蔽其弹幕展示与语音播报，支持批量管理。

#### 核心功能

- 通过用户名/UID手动添加黑名单

- 被禁言用户自动拉入黑名单

- 支持单条移除、批量导入导出黑名单

- 黑名单用户弹幕全维度屏蔽，无展示、无播报

#### 验收标准

黑名单匹配准确率100%、屏蔽响应＜5ms、支持万级用户存储

### 4\.6 上舰特效展示（免费）

**功能描述**: 监听直播间舰长开通事件，在工具本地窗口渲染专属视觉特效、播放定制音效，仅本地可见，不对外发送任何弹幕消息。

#### 核心功能

- 区分首次上舰、续费上舰、多舰长连击专属特效

- 特效队列机制，多事件同时触发有序展示

- 支持自定义特效配色、展示时长、弹窗位置

- 配套专属音效，动画与音效同步播放

#### 验收标准

## 9\. 风险与规避方案

### 9\.1 AI服务可用性风险

**风险点**：第三方AI服务超时、限流或不可用，导致本地文案生成失败。

**规避方案**：明确展示生成失败状态，保留人工输入能力；AI异常不影响直播间监听、提醒、统计和录制。

### 9\.2 内容合规风险

**风险点**：AI生成违规、低俗、引战内容，造成直播间违规处罚。

**规避方案**：双层内容安全校验，本地词库\+大模型双重拦截，连续违规自动暂停AI功能，强制风险告知用户确认后才可使用。

### 9\.3 接口失效风险

**风险点**：B站直播接口更新，导致监听功能失效。

**规避方案**：版本快速迭代适配，工具自动检测接口异常，异常后自动降级保留本地监控能力，等待版本更新修复。

### 9\.4 性能卡顿风险

**风险点**：高并发弹幕、多功能同时运行导致工具卡顿、闪退。

**规避方案**：高并发自动限流、任务队列机制、资源占用限制，功能解耦运行，单一功能异常不影响整体工具使用。
