# AI 文案辅助

AI 文案辅助功能集成了 AI 大模型，用于在工具内生成和查看回复建议。该功能不会根据弹幕事件自动触发，也不会向直播间发送弹幕。

## 功能特点

### 文案生成

- **上下文理解**: 理解弹幕上下文
- **多轮对话**: 支持多轮对话
- **个性化回复**: 根据用户特点回复
- **情感分析**: 分析弹幕情感

### 模型支持

- **OpenAI**: GPT-3.5、GPT-4
- **Claude**: Claude-3
- **文心一言**: ERNIE Bot
- **通义千问**: Qwen
- **自定义模型**: 支持自定义模型

### 提示词管理

- **系统提示词**: 设置 AI 角色和行为
- **用户提示词**: 自定义用户提示词
- **模板管理**: 管理提示词模板
- **变量替换**: 支持变量替换

### 生成控制

- **回复长度**: 控制回复长度
- **回复风格**: 设置回复风格
- **敏感词过滤**: 过滤敏感内容
- **回复审核**: 审核回复内容

## 使用方法

### 配置 AI

1. 进入「设置」->「AI 设置」
2. 选择 AI 模型
3. 输入 API Key
4. 测试连接
5. 保存设置

### 设置提示词

1. 进入「设置」->「AI 设置」
2. 点击「提示词设置」
3. 编辑系统提示词
4. 设置回复风格
5. 保存设置

### 能力边界

- AI 配置只用于本地文案生成。
- 不监听弹幕、礼物或上舰事件来自动生成内容。
- 不使用主播账号发送弹幕。

## 最佳实践

- 设置合适的系统提示词
- 控制回复长度，避免过长
- 定期更新提示词
- 检查 AI 生成内容质量
