# 弹幕管理

智能弹幕管理是 Bilibili 直播助手的核心功能之一。

## 功能特点

### 自动回复

根据预设的关键词规则，自动回复观众的弹幕：

- **关键词匹配**: 支持精确匹配和模糊匹配
- **变量替换**: 支持在回复中使用变量（如用户名、礼物名等）
- **优先级设置**: 设置不同规则的优先级
- **冷却时间**: 避免频繁回复同一用户

### 弹幕过滤

过滤不需要的弹幕内容：

- **敏感词过滤**: 过滤敏感词汇
- **广告过滤**: 过滤广告内容
- **刷屏过滤**: 过滤刷屏弹幕
- **自定义过滤**: 自定义过滤规则

### 弹幕播报

将弹幕转换为语音播报：

- **TTS 引擎**: 支持多种 TTS 引擎
- **语音选择**: 选择不同的语音
- **语速调节**: 调节播报语速
- **音量控制**: 控制播报音量

### 弹幕队列

智能管理弹幕发送队列：

- **队列管理**: 管理待发送的弹幕
- **发送间隔**: 设置弹幕发送间隔
- **优先级**: 设置弹幕发送优先级
- **合并发送**: 合并多条弹幕一起发送

## 使用方法

1. 进入「设置」页面
2. 选择「弹幕设置」
3. 配置自动回复规则
4. 设置过滤关键词
5. 启用弹幕播报（可选）

- 定期更新敏感词库
