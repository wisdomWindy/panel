# 弹幕管理

弹幕观测是 Bilibili 直播助手的核心功能之一。

## 功能特点

### 弹幕过滤

过滤不需要的弹幕内容：

- **敏感词过滤**: 过滤敏感词汇
- **广告过滤**: 过滤广告内容
- **刷屏过滤**: 过滤刷屏弹幕
- **自定义过滤**: 自定义过滤规则

### 弹幕播报

将弹幕转换为语音播报：

- **TTS 引擎**: 支持多种 TTS 引擎
- **语音选择**: 选择不同的语音
- **语速调节**: 调节播报语速
- **音量控制**: 控制播报音量

## 使用方法

1. 进入「设置」页面
2. 选择「过滤设置」并配置过滤关键词
3. 选择「语音播报」并启用弹幕播报（可选）
