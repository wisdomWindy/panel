# 礼物音效

礼物音效系统可以为不同的礼物设置专属音效，增强直播互动氛围。

## 功能特点

### 自定义音效

为每个礼物单独绑定一个音效文件：

- **礼物列表**: 通过 Bilibili API 自动获取礼物列表
- **音效上传**: 支持上传本地 MP3 文件
- **音效预览**: 在设置页面预览音效效果
- **批量管理**: 支持批量导入/导出音效配置

### 播放控制

灵活的音效播放控制：

- **音量控制**: 独立控制礼物音效音量
- **播放模式**: 支持单次播放或循环播放
- **冷却时间**: 设置同一礼物音效的最小播放间隔
- **优先级**: 高价值礼物音效可设置更高优先级

### 音效队列

智能管理多个音效同时播放：

- **队列管理**: 多个礼物同时到达时，音效按队列顺序播放
- **优先级排序**: 按优先级播放音效
- **淡入淡出**: 支持音效淡入淡出效果
- **静音时段**: 支持设置静音时段

## 使用方法

1. 进入「礼物音效」页面
2. 系统自动加载礼物列表
3. 选择要配置音效的礼物
4. 上传音效文件
5. 设置播放参数
6. 保存配置

## 音效要求

- **格式**: 支持 MP3、WAV、OGG、FLAC、AAC
- **大小**: 1KB ~ 10MB
- **时长**: 建议 1-10 秒

## 最佳实践

- 选择与礼物主题相关的音效
- 合理设置音量，避免过大或过小
- 设置适当的冷却时间，避免音效过于频繁
- 使用预览功能测试音效效果
