# 功能介绍

Bilibili 直播助手是一款功能强大的直播辅助工具，专为 Bilibili 主播设计。

## 核心功能

### 🎙️ 智能弹幕管理

- **弹幕自动回复**: 根据关键词自动回复弹幕
- **弹幕过滤**: 过滤敏感词和垃圾弹幕
- **弹幕播报**: 将弹幕转换为语音播报
- **弹幕队列**: 智能管理弹幕发送队列

### 🎁 礼物音效系统

- **自定义音效**: 为不同礼物设置专属音效
- **音量控制**: 独立控制礼物音效音量
- **播放模式**: 支持单次播放和循环播放
- **冷却时间**: 设置同一礼物音效的最小播放间隔

### 🎬 直播录制

- **自动录制**: 自动录制直播内容
- **精彩标记**: 标记精彩时刻
- **格式支持**: 支持多种视频格式
- **存储管理**: 智能管理录制文件

### 🤖 AI 对话

- **智能回复**: 基于 AI 大模型的智能回复
- **上下文理解**: 理解弹幕上下文
- **多模型支持**: 支持多种 AI 模型
- **自定义提示词**: 自定义 AI 回复风格

### 🔌 插件系统

- **插件市场**: 丰富的插件生态
- **自定义开发**: 支持自定义插件开发
- **插件管理**: 方便的插件安装和管理
- **沙箱隔离**: 插件运行在沙箱环境中

### 🌐 多语言支持

- **中文界面**: 完整的中文支持
- **英文界面**: 完整的英文支持
- **自动检测**: 自动检测系统语言
- **手动切换**: 支持手动切换语言

## 技术特性

- **高性能**: 优化的性能表现
- **低资源占用**: 合理的资源占用
- **跨平台**: 支持 Windows、macOS、Linux
- **自动更新**: 支持自动检查更新
