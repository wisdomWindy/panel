# 插件系统

插件系统提供了可扩展的插件架构，支持自定义功能开发。

## 功能特点

### 插件架构

- **模块化设计**: 插件独立运行
- **沙箱隔离**: 插件运行在沙箱环境中
- **API 丰富**: 提供丰富的 API 接口
- **事件驱动**: 基于事件的通信机制

### 插件管理

- **安装卸载**: 方便的插件安装和卸载
- **启用禁用**: 支持启用和禁用插件
- **配置管理**: 管理插件配置
- **版本管理**: 管理插件版本

### 插件类型

- **弹幕插件**: 扩展弹幕功能
- **礼物插件**: 扩展礼物功能
- **录制插件**: 扩展录制功能
- **工具插件**: 提供工具功能

### 插件市场

- **官方插件**: 官方提供的插件
- **社区插件**: 社区开发的插件
- **插件评分**: 插件评分和评价
- **插件更新**: 插件自动更新

## 使用方法

### 安装插件

1. 进入「插件管理」页面
2. 浏览插件市场
3. 选择插件
4. 点击安装
5. 启用插件

### 配置插件

1. 进入「插件管理」页面
2. 选择已安装的插件
3. 点击「设置」
4. 配置插件参数
5. 保存设置

### 开发插件

1. 查看插件开发文档
2. 创建插件项目
3. 实现插件功能
4. 测试插件
5. 发布插件

## 插件 API

### 事件监听

```javascript
// 监听弹幕事件
plugin.on('danmaku', (data) => {
  console.log('收到弹幕:', data);
});

// 监听礼物事件
plugin.on('gift', (data) => {
  console.log('收到礼物:', data);
});
```

### 存储数据

```javascript
// 保存数据
plugin.storage.set('key', value);

// 读取数据
const value = plugin.storage.get('key');
```
