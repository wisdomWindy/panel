# 录制功能

直播录制功能可以自动录制直播内容，支持精彩时刻标记。

## 功能特点

### 自动录制

- **自动开始**: 连接直播间后自动开始录制
- **自动停止**: 直播结束时自动停止录制
- **断点续录**: 网络断开后自动重连并继续录制

### 精彩标记

- **手动标记**: 手动标记精彩时刻
- **自动标记**: 根据礼物、弹幕等自动标记
- **标记管理**: 管理已标记的精彩时刻

### 格式支持

- **视频格式**: MP4、FLV、MKV
- **音频格式**: MP3、AAC
- **画质选择**: 支持不同画质录制

### 存储管理

- **自动清理**: 自动清理过期录制文件
- **空间管理**: 监控存储空间使用
- **文件命名**: 自动命名录制文件

## 使用方法

### 开始录制

1. 连接直播间
2. 点击「开始录制」按钮
3. 等待录制开始

### 停止录制

1. 点击「停止录制」按钮
2. 等待录制完成
3. 查看录制文件

### 标记精彩时刻

1. 在录制过程中点击「标记」按钮
2. 输入标记名称（可选）
3. 保存标记

### 查看录制文件

1. 进入「录制」页面
2. 查看录制文件列表
3. 播放或导出录制文件

## 设置选项

### 录制目录

设置录制文件的保存位置。

### 录制格式

选择录制文件的格式。

### 画质设置

设置录制画质。

### 自动清理

设置自动清理规则。

## 最佳实践

- 确保存储空间充足
- 选择合适的录制格式
- 定期清理不需要的录制文件
- 使用标记功能记录精彩时刻
