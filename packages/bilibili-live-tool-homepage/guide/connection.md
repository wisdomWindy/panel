# 连接直播间

## 获取直播间 ID

### 方法一：从直播间页面获取

1. 打开 Bilibili 直播页面
2. 进入目标直播间
3. 查看浏览器地址栏，URL 中的数字就是直播间 ID

例如：`https://live.bilibili.com/123456`，直播间 ID 就是 `123456`

### 方法二：从主播主页获取

1. 打开主播的个人主页
2. 点击「直播」标签
3. 查看直播间 ID

## 连接步骤

### 1. 启动应用

```bash
cd packages/bilibili-live-tool
pnpm dev
```

### 2. 进入连接页面

启动应用后，默认进入「连接」页面。

### 3. 输入直播间 ID

在输入框中输入直播间 ID。

### 4. 点击连接

点击「连接」按钮，等待连接成功。

### 5. 连接成功

连接成功后，会显示连接状态和直播间信息。

## 连接状态

- **连接中**: 正在建立连接
- **已连接**: 连接成功，可以接收弹幕和礼物信息
- **连接失败**: 连接失败，请检查直播间 ID 和网络
- **已断开**: 连接已断开，可以重新连接

## 高级设置

### 自动重连

启用自动重连功能，当连接断开时自动重新连接。

### 心跳间隔

设置心跳包发送间隔，保持连接活跃。

### 代理设置

配置网络代理，解决网络访问问题。

## 常见问题

### Q: 无法连接直播间？

A: 请检查：
- 直播间 ID 是否正确
- 网络连接是否正常
- 直播间是否正在直播
- 防火墙是否阻止连接

### Q: 连接后无法接收弹幕？

A: 请检查：
- 连接状态是否正常
- 弹幕接收是否启用
- 网络是否稳定

### Q: 连接频繁断开？

A: 请尝试：
- 启用自动重连
- 调整心跳间隔
- 检查网络稳定性
