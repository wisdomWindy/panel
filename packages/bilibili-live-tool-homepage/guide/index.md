# 快速开始

本指南将帮助您快速上手 Bilibili 直播助手。

## 系统要求

- **操作系统**: Windows 10+、macOS 10.15+、Ubuntu 20.04+

## 首次使用

### 连接直播间

1. 启动应用后，进入「连接」页面
2. 输入直播间 ID
3. 点击「连接」按钮
4. 等待连接成功

### 配置弹幕

1. 进入「设置」页面
2. 选择「弹幕设置」
3. 配置弹幕自动回复规则
4. 设置弹幕过滤关键词

### 设置礼物音效

1. 进入「礼物音效」页面
2. 从礼物列表中选择礼物
3. 上传音效文件
4. 设置播放参数

## 常见问题

### Q: 无法连接直播间？

A: 请检查：
- 直播间 ID 是否正确
- 网络连接是否正常
- 直播间是否正在直播

### Q: 音效无法播放？

A: 请检查：
- 音效文件是否存在
- 音效格式是否支持
- 系统音量是否正常

### Q: 如何更新应用？

A: 应用会自动检查更新，也可以在设置中手动检查更新。
