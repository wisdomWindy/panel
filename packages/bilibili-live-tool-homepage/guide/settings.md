# 功能设置

## 设置页面

进入「设置」页面，可以配置各项功能。

## 弹幕设置

### 弹幕过滤

1. 进入「设置」->「过滤设置」
2. 添加敏感词
3. 设置过滤模式
4. 保存设置

### 弹幕播报

1. 进入「设置」->「语音播报」
2. 选择 TTS 引擎
3. 选择语音
4. 设置语速和音量
5. 保存设置

## 礼物音效设置

### 添加音效

1. 进入「礼物音效」页面
2. 选择礼物
3. 上传音效文件
4. 设置播放参数
5. 保存配置

### 批量导入

1. 进入「礼物音效」页面
2. 点击「导入」
3. 选择配置文件
4. 确认导入

## 录制设置

### 自动录制

1. 进入「设置」->「录制设置」
2. 启用自动录制
3. 设置录制目录
4. 设置录制格式
5. 保存设置

### 存储管理

1. 进入「设置」->「录制设置」
2. 点击「存储管理」
3. 查看录制文件
4. 删除不需要的文件

## AI 设置

### 模型配置

1. 进入「设置」->「AI 设置」
2. 选择 AI 模型
3. 输入 API Key
4. 测试连接
5. 保存设置

### 提示词设置

1. 进入「设置」->「AI 设置」
2. 点击「提示词设置」
3. 编辑系统提示词
4. 设置回复风格
5. 保存设置
