- Adds Qwen3-TTS as the speech backend for live-event voice broadcast and AI voice replies, with a configurable local service, voice, instruction, timeout, and automatic fallback to the system voice.
- Adds a one-click Qwen3-TTS 1.7B model download on the dashboard, with live progress and install status.

- Keeps deterministic Windows x64, macOS Intel, and macOS Apple Silicon release artifacts.
