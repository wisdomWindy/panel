# biliLiveHelper 0.4.0

本次版本按 PRD v2 完成主界面重构与开放平台长连能力补全。

## 主界面重构

- 全新四区布局：48px 顶部工具栏 + 208px 左侧导航 + 内容区 + 状态栏
- 十个导航页全部对齐设计稿：直播间、弹幕面板、数据看板、排行榜、风控中心、提醒配置、语音播报、直播录制、AI 助手、系统设置
- 风控中心、提醒配置、系统设置改为分组页签，旧路径保留重定向，深链不断
- 统一设计令牌（`styles/theme.css`），全仓库不再有页面级 `dark:` 硬编码配色
- 新增「直播间」首屏：房间信息、四张指标卡、最近事件流

## 弹幕与统计

- 弹幕面板：身份 Chip 过滤、身份图例侧栏、行内头像、礼物与醒目留言高亮
- 弹幕显示偏好（等级 / 勋章 / 时间 / 最大条数）现在真正生效
- 排行榜改为送礼 / 弹幕 / 舰长三榜并排
- 看板新增互动点赞指标

## 开放平台长连（PRD 9.1.1 全量）

- `DM`、`SEND_GIFT`、`GUARD`、`LIVE_ROOM_ENTER` 事件采集
- `SUPER_CHAT` 醒目留言：金额、时长、高亮展示
- `SUPER_CHAT_DEL` 撤回：按留言 id 移除展示，营收统计保留
- `LIKE` 汇总为互动计数，不逐条展示
- `LIVE_START` / `LIVE_END` 场次边界：重置本场统计、驱动自动录制
- `DM_MIRROR` 显式忽略，避免重复计数
- `INTERACTION_END` 视为连接失效并重连

## 录制

- 高光片段自动截取：打点后从录制文件 remux 出前后窗口片段
- 录制断流自动重连：最多三次，写入续录文件，超限停止并提示
- 录制页支持直接填房间号开录，无需先连接直播间

## AI 语音回复

- 开启前强制数据外发确认（明示弹幕文本与昵称将发送到所配置模型端点）
- 生成结果回显本次实际使用的上下文

## 数据与隐私

- 数据保留期可配：事件日志 90 天、AI 日志 30 天、统计 180 天，均支持改为更短或永久
- 定时清理任务：启动时与每 6 小时执行
- 新增「数据与隐私」设置页：分项清空事件日志 / AI 日志 / 缓存 / 全部数据，均二次确认
- 运行日志固定保留 30 天并按大小滚动，策略在界面明示

## 系统

- 新增系统托盘：显示主窗口 / 退出
- 关于页显示当前运行平台，非 Windows 明确提示未完整验证
- 错误码统一为 `PREFIX_SEMANTIC` 大写形式（如 `ROOM_INVALID_ID`），PRD 新增 `MEMBER` 分类
- 路径白名单契约测试：任何 IPC 模块接受裸路径或直接触碰文件系统都会失败

## 验证

- Rust 单元测试 202 项通过（`--features member` 203 项），含 4 项需外部资源的真机用例
- 前端 51 个测试文件 / 174 项通过，TypeScript 类型检查与生产构建通过
- 高光片段与断流重连已用真实 FFmpeg 实跑验证
