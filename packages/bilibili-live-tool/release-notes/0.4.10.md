Changes:

- Installing the speech runtime now uses a package mirror by default (Tsinghua), which turns the first-run dependency download from hours into minutes on mainland networks.
- 语音播报 settings gained a 依赖下载源 selector: 清华大学镜像 / 阿里云镜像 / 官方源（不使用镜像）, so the mirror can be switched or disabled entirely.
- The choice is persisted with the speech configuration and passed to `pip install --index-url`; choosing 官方源 restores pip's own default index.
- Older stored configurations without the new field fall back to the mirror instead of failing validation.
- Adds tests for the mirror defaults and the official-source case.
