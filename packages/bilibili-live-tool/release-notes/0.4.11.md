Changes:

- Fixes the stray black window: every console child (Python, pip, FFmpeg, tar) is now spawned without a console, and Python runs through `pythonw.exe`, which removes the Windows Terminal window that appeared when the speech service started on Windows 11.
- The one-click speech install now runs only from an enable action: 语音播报, AI 语音回复, or a stored configuration that already has 播报 enabled at launch. Visiting the speech page installs and starts nothing.
- A configuration with 播报 enabled now repairs itself on start-up: the app recreates the virtualenv, installs the requirements with the configured mirror, starts the service and downloads the default model without any interaction.
- AI 语音回复 shares that pipeline, so enabling it from AI 助手 prepares the same runtime and service.
- The model card no longer shows the "语音服务未启动" badge or warning, since the service is managed automatically; clicking 下载模型 while it is still starting explains what to do.
