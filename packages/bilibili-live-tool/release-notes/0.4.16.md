Changes:

- The speech checkpoint is now downloaded through ModelScope, the model publisher's own mirror, instead of HuggingFace which is unreachable from mainland networks. This is the fix for the raw `OSError: We couldn't connect to 'https://huggingface.co'` shown in the speech settings; HuggingFace remains available with `QWEN3_TTS_HUB=hf`.
- The engine adapts to the machine instead of the flags: it uses the CPU when CUDA is unavailable (float32 there), and falls back to sdpa attention when flash-attn is not installed, so a plain desktop can run the service.
- Network failures during model loading now show 无法连接模型下载源（HuggingFace/ModelScope），请检查网络后重试 instead of a Python traceback.
- `modelscope` is part of the speech requirements and of the runtime probe, so an existing environment installs that one package on the next visit to the speech page.
- The speech page keeps a single action bar (probe, test, reset defaults, save) instead of two separate save/test areas; saving persists both the broadcast form and the Qwen3 configuration.
