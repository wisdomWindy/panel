Changes:

- The application is now called liver everywhere it is visible: the window title, the toolbar brand, the page titles and the tray tooltip.
- The installers and the installed program are renamed too. Windows ships `liver_<version>_Windows_x64-setup.exe` and macOS ships `liver_<version>_macOS_AppleSilicon.dmg` / `liver_<version>_macOS_Intel.dmg`, and the program installs as `liver.exe`.
- Upgrading from 0.4.16 or older: the new version installs into its own `liver` folder. Your configuration, the speech runtime and the downloaded speech model are kept, because the application identifier is unchanged. Remove the old `biliLiveHelper` installation and its shortcut afterwards.
