Changes:

- The speech page warns when the local engine runs on the CPU: about half a second per character, so roughly five seconds for a ten-character remark. The notice appears only while Qwen3-TTS is enabled and the service reports `cpu`; machines with a GPU see nothing.
- Finishing the one-click speech preparation now ends with a 语音服务已就绪 confirmation instead of the progress panel simply disappearing.
- The AI helper gained 生成一次测试回复 in its result card. It runs the normal generation path with a fixed prompt and enqueues the reply for speech, so the AI → queue → TTS pipeline can be checked without a live broadcast.
- The open platform credentials are compiled in again, so a plain build works without any environment setup. A build-time or run-time `BILI_OPEN_*` value still takes precedence, which allows rotating a key without editing the source.
- README: download links and asset names updated to `liver`, plus an upgrade note for installations older than 0.4.17 and a section about the open platform credentials.
