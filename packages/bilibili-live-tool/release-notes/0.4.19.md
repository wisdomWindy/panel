Changes:

- The recording page keeps its numbers live: 本场时长, 时长, 大小 and 剩余空间 used to stay at 00:00:00 / 0 B / -- for the whole recording because the backend only pushed status on transitions and reported a hard-coded zero. The page now polls the status once per second while a recording runs, and the status reports the real size of the file being written plus the free space on the target volume.
- 停止录制 no longer fails with 本地媒体操作失败. Stopping terminates the recorder, and that non-zero exit was treated as a failure, which also left the row stuck in 录制中; a requested stop is now a normal exit, so the row is finalised with its real size.
- Records left in 录制中 by an earlier crash are settled to 部分文件 at start-up, and the 磁盘占用 gauge includes the file that is currently being written.
- 预览 now actually plays the recording. The range response sent application/octet-stream, the URL used a bare custom scheme that WebView2 does not serve, and the CSP had no media-src; the response now carries a real media type, the URL is platform-aware and the CSP allows the preview scheme. 预览 is disabled with an explanation while a recording is still being written.
- The recording settings dialog opens while a recording is running instead of the 设置 button ignoring the click: the dialog explains that settings are locked until the recording stops and renders the form read-only.
