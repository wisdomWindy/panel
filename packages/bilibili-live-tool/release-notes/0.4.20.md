Changes:

- Deleting a 高光时刻 no longer fails with 配置内容无效，请检查后重试. Deleting stages the clip file for removal, and staging treated a missing file as invalid input, so a highlight whose clip was never written (or was removed from the folder) could not be deleted. Missing files are skipped now, and deleting an already-deleted highlight returns instead of raising, so a double click is harmless too.
- Removed three renderer modules that no longer had importers — the MediaRecorder composable, the legacy variable replacer and the renderer logger — which takes 401 unreachable lines out of the bundle.
