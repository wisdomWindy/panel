Changes:

- The 预览 button on a recording row is now 打开文件夹. Clicking it opens the folder that holds the recording in Explorer, Finder or xdg-open, so the file can be played with whatever player the system already uses. It goes through a dedicated command that takes the recording id and resolves the parent folder internally; no path crosses the IPC boundary.
- Highlight preview is unchanged and still plays inside the app, because a highlight is a finished clip of its own.
