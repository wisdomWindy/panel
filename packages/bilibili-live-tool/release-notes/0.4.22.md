Changes:

- Several rooms can record at the same time. Every click on 开始录制 adds a task instead of being refused while another recording runs; each task owns an independent recorder process, its own watchdog, highlight window and outcome, and the page lists them with room, state, elapsed time and size plus per-task 停止 / 手动标记 buttons and a 全部停止 action.
- A host going offline is no longer reported as an error. When the room reports offline during a recording the session ends normally and the row is finalised as completed; a real network drop still surfaces as 推流已中断，已保存当前录像内容.
- The recording page shows translated text instead of raw codes: recording.error, ROOM_OFFLINE, RECORD_START_FAILED and RECORD_FINALIZE_FAILED now have Chinese and English labels, and the 最近错误 line localises the code.
