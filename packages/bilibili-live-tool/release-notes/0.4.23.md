Changes:

- The recording page gained 清理冗余文件. It removes recording records whose video file is missing or empty, deletes their highlights and clips with them, and clears zero-byte files that follow the recorder's own naming in the recording folder. The confirm dialog explains exactly what is removed, and the toast reports how many records and files were deleted and how much space was freed.
- The cleanup never touches files the operator put in the folder: only `<room>-<stamp>[-partN].<mp4|flv|mkv|ts>` names are considered, only empty ones are deleted, and continuation segments that still hold data are kept. Running recordings are skipped as well.
