Changes:

- FFmpeg now ships inside the Windows installer. The LGPL shared build is bundled as a resource, so recording works right after installation instead of asking the operator to download 170 MB first; the in-app installer stays as a repair path. The installer grows from 7.8 MB to 57.1 MB, still inside the 60 MB budget.
- The long connection keeps monitoring instead of giving up. Reconnects are no longer capped at ten attempts: the session retries with a 5s → 10s → 30s backoff and keeps waiting through 下播, so the room is picked up again the next time it goes live. `INTERACTION_END` now only appears on heartbeat expiry, and the 「重连失败，请手动重试」 prompt is gone.
- 记住身份码: connect once and the next launch reconnects by itself. The identity code and the auto-connect flag are stored locally, the toolbar pre-fills the code, and the connection is restored after start-up, so auto-record, reminders and speech fire again without another click. Turning the switch off deletes the stored code.
- Fixed installers that could never connect. A build-time `BILI_OPEN_*` value that was present but empty (an unset CI secret) used to shadow the credentials compiled into the crate, so the packaged app replaced the transport with a failing stub and rejected every connection without sending a request. Blank values now fall back to the embedded constants, and the release workflow warns when the secrets are missing.
- 语音播报 gained its 测试播报 button back, and the button tests the selected engine instead of only the Qwen3 service.
- AI voice: 「温柔桃子」 is no longer an alias for the system voice. The id now synthesises through Qwen3-TTS with the AI reply voice configured on the 语音播报 page (Serena by default), and the audio-route dialog explains when Qwen3-TTS has to be enabled first.
- The recording page no longer fails to load when FFmpeg 来源 is 系统已安装 or 应用内安装. The payload adapter accepted only two of the four legal values, so the whole page showed "Malformed media payload: recordingConfig.ffmpegSource"; all four are accepted now and 应用内安装 shows its own label.
- Removed the 更新日志 page and its tab. Update checking stays available in 设置 → 关于.
- Connection failures now show their real cause (missing credentials, invalid identity code, rejected request) instead of a generic retry prompt.
