Changes:

- The 直播间 page now fills itself in once the connection completes. The status event carried neither the anchor name nor the online count, so the page kept showing 未连接直播间 and a hard-coded 主播 未知 even while connected; it now receives the room name, room id, online count and broadcast state on every status change.
- The 直播中 badge reports the actual broadcast state instead of the connection state. Because the long connection deliberately survives the end of a stream, the old badge claimed 直播中 for as long as the app was connected. The state now follows `LIVE_START` / `LIVE_END`, is seeded by a single read-only probe when the connection is established mid-stream, and the badge distinguishes 直播中 / 未开播 / 检测中.
- 语音播报 gained one engine dropdown: 系统引擎 or Qwen3-TTS. The engine used to be split across 「引擎与音色」 and a separate 「Qwen3-TTS 语音服务」 panel, and the cloud slot was in fact the Qwen3 engine with no hint of it. Choosing an engine now reveals that engine's voices and settings in the same card: the system engine keeps 音色 / 语速 / 音量, Qwen3-TTS adds its service status, enable switch, fallback, language, AI reply voice, timeout, package mirror and voice instruction.
- Choosing the Qwen3-TTS engine also enables the service and makes the chosen voice the Qwen3 default, so broadcast and AI replies no longer disagree about which voice was selected.
- Renamed the engine options to what they actually are: 系统默认 → 系统引擎, 云端 → Qwen3-TTS.
