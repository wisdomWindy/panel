- The recording page reports the space it actually uses. The disk gauge and 大小 added the runtime's last-session byte count even while nothing was recording, so deleting the file left 2.8 MiB on screen forever; only a running task counts now, and deleting a recording re-reads the status so the freed space and the size update immediately.
