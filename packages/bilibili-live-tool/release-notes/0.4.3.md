Changes:

- Moves the updater manifest to the default branch: the app now polls `raw.githubusercontent.com/<repo>/main/<channel>/latest.json`, so the release pipeline no longer creates or writes an `updates` branch.
- Keeps channel manifests isolated by path, so a future member build cannot overwrite the free manifest.
- Notes for anyone on 0.4.2 or earlier: their build still polls the retired branch, so automatic updates stop until one manual install of this release.
