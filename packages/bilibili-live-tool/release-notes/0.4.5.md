Changes:

- Makes startup survive a degraded local database: the data-maintenance service is now optional instead of aborting the process, and its scheduled cleanup is skipped when the database is unavailable.
- Adds a startup crash log. Any panic before the logging subsystem exists is now appended to `%LOCALAPPDATA%\com.bilibili.live-tool\startup-crash.log`, so an instant exit leaves evidence instead of nothing.
- Treats the tray icon and file logging as optional at launch: a missing icon, menu, or log directory now degrades to "no tray" or "no file log" instead of stopping the app.
- Reported symptom: the previous build could exit immediately on launch on some machines. If it still happens, please send the crash log above.
