Changes:

- Recording works out of the box: files go to a `download` folder beside the executable (no folder dialog first), a system-wide FFmpeg is detected automatically (PATH, winget, chocolatey, scoop), and a missing FFmpeg now raises an install prompt instead of a disabled button.
- Fixes the empty-instruction crash: opening 语音播报 failed with "Malformed media payload" for the default, empty voice instruction.
- Fixes the ACL error that made 数据与隐私 unusable, and adds a contract test that fails when a command is not granted by any capability.
- Fixes navigation: clicking 风控中心 or 提醒配置 used to replace the first-level entry with its children; the header now stays and only the children expand.
- Cancelling a folder picker is no longer reported as an error, and backend error codes are shown in the interface language.
- Creates a fresh database when the existing one cannot be prepared (renamed to `app.db.broken-<timestamp>`), and no longer copies a legacy per-user database into the install directory.
- The Qwen3-TTS model download moved from 数据看板 to 语音播报, where the model is actually used.
- The AI model field is now a searchable list of 20 mainstream models, with 添加模型 to keep your own ids.
- 关于与许可 always lists the third-party components and model licences (Qwen3-TTS Apache-2.0, FFmpeg LGPL-2.1-or-later) instead of "暂不可用".
- Removes the unreachable 老爷 identity from the danmaku legend, since the long-link protocol never reports it.
