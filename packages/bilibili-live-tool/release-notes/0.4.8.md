Changes:

- 语音播报 now owns the local Qwen3-TTS service: enabling the switch starts it in the background, a cold start with 播报 already on starts it automatically, and the extra 启动 button is gone.
- The service script ships with the installer and the launcher finds Python and starts `server.py` itself, writing its logs into the app log directory.
- Reserved OS port ranges (Hyper-V / WinNAT reserve 7997-8096 on many machines) no longer break the service: the launcher probes the configured port, falls back to a free one and stores the working address.
- The 服务地址 field is gone from the speech settings; the app manages the endpoint internally.
- The model download button now reacts: it starts the service first, shows an indeterminate bar while preparing, a live percentage while downloading, stays disabled during the transfer and re-enables afterwards.
- The voice pickers are never empty: the nine speakers documented for Qwen3-TTS CustomVoice are compiled in as a fallback (live service ids still win), 播报音色 is now selectable, and both selectors accept a typed id.
