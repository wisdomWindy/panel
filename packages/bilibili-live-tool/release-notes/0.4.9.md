Changes:

- Enabling 语音播报 now prepares everything in one step: the app creates its own Python virtualenv, installs `services/qwen3-tts/requirements.txt` into it (torch, qwen-tts, transformers, soundfile, numpy), verifies the imports, starts the speech service with that interpreter and triggers the default model download.
- A preparation dialog reports each stage instead of leaving a silent spinner, and the first-run hint explains the roughly 6–7 GB download.
- `requirements.txt` ships with the bundle next to `server.py`, both are exposed by the Python installer, and the service prefers the managed virtualenv over any interpreter on PATH.
- Dependency installation is idempotent: an existing environment is verified with an import probe and skipped, so a retry resumes instead of reinstalling.
- Pip output is written to `venv.log`, `pip.log` and `deps.log` in the app log directory, and preparation failures surface an actionable message instead of a generic retry hint.
- Fixes the virtualenv creation itself, which previously failed because the working directory did not exist yet.
